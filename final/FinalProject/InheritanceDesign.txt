

CLASSES AND RESPONSIBILITIES
- Event: Base class. Tracks title, description, date, time, and Address. Produces standard details, short description, and virtual full details.
- Lecture: Derived from Event. Adds speaker name and capacity. Overrides full details.
- Reception: Derived from Event. Adds RSVP email. Overrides full details.
- OutdoorGathering: Derived from Event. Adds weather forecast. Overrides full details.
- Address: Tracks street, city, state/province, and country. Returns formatted address and USA check.
- Program: Creates one event of each type, sets values, and displays all three marketing messages.

PROGRAM FLOW
Main()
1. Create Address objects for each event.
2. Create one Lecture, set speaker name and capacity.
3. Create one Reception, set RSVP email.
4. Create one OutdoorGathering, set weather forecast.
5. For each Event:
   - Display GetStandardDetails().
   - Display GetFullDetails() using virtual dispatch.
   - Display GetShortDescription().
6. End program.

DESIGN NOTES
- Shared data and methods are in Event to avoid duplication.
- Derived classes add only their specific data and override GetFullDetails().
- Address is a separate class used by Event.
- All member variables are private/protected; behavior is exposed through methods.
